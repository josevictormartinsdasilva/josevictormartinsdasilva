## 🚀 Alguns projetos 

### 🤖 [abap-full-stack-sample](https://github.com/josevictormartinsdasilva/abap-full-stack-sample)

Uma **arquitetura multiagente** para desenvolvimento SAP de ponta a ponta, orquestrada pelo Claude Code. Cada agente tem uma especialidade e se conecta ao sistema via MCP:

- **`abap-rap-dev`** — ABAP Cloud / RAP / Clean Core: CDS View Entities, Metadata Extensions, Behavior Definitions e serviços OData V4.
- **`abap-classic-dev`** — ABAP Clássico / RICEFW: reports, function modules, BAPIs, Dynpro, enhancements e estimativa de esforço.
- **`fiori-elements-dev`** — Fiori Elements / SAPUI5: Page Map, rotas, Flexible Column Layout e lint do frontend.
- **`abap-qa-auditor`** — Governança: inspeções ATC, QuickFixes, testes ABAP Unit e política de zero erros antes do transporte.

Tudo guiado por um padrão corporativo de desenvolvimento e convenções de nomenclatura versionadas no próprio repositório.

### 🧪 [abap-offstack-claude-sample](https://github.com/josevictormartinsdasilva/abap-offstack-claude-sample)

Mostra como rodar **lint e testes unitários ABAP fora do SAP** — localmente ou numa esteira CI/CD — usando `abaplint` e `abap-transpiler` (o código ABAP é transpilado para JavaScript e executado com Node.js). Inclui também um guia prático de **Claude Code para desenvolvedores ABAP**: configuração do `CLAUDE.md`, comandos personalizados para revisão de BAPIs, CDS e análise de dumps, escolha de modelo e uso de subagentes.
